# Changelog

- Added strict study, external, context, and excluded file pools.
- Added incremental indexing, source hashes, extraction quality scores, precise DOCX/XLSX/PPTX locators, PDF fallback extraction, and optional OCR.
- Added hybrid BM25 and local semantic retrieval, bilingual glossary expansion, comparability reranking, DOI/PMID/hash deduplication, and published-version preference.

- Added exact source excerpt sealing, excerpt hashes, source mutation invalidation, formal JSON Schema enforcement, and study-result locator verification.

- Added bilingual causal-language checks, reverse outlines, structured semantic audits, citation deletion tests, journal constraints, and a mandatory fresh compile gate.
- Added BibTeX, RIS, and EndNote XML mapping, v1 migration, legacy-draft revision intake, evidence exports, and safe DOCX copy writeback.
- Split the Python implementation into workspace, ingestion, indexing, evidence, argument, audit, compiler, migration, and output modules.
- Expanded automated tests and added GitHub Actions CI.
