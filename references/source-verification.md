# Source Verification

A verified claim requires:

- `source_file` in the external-evidence pool;
- current SHA-256 source hash;
- exact indexed locator;
- verbatim supporting excerpt;
- SHA-256 excerpt hash;
- statement no stronger than the excerpt;
- forbidden inferences;
- linked study result and role.

`seal-card` calculates hashes only after locating the excerpt. Any source modification invalidates the card. Reindex, reread, reseal, and rerun validation.
