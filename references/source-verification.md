# 来源核验规范

## 定位格式

- PDF：`page 6, Results, paragraph 2` 或 `page 8, Table 2, row X`；
- DOCX：章节标题、段落首句、表号；
- PPTX：slide 12；
- XLSX：sheet 名称、单元格范围；
- TXT/MD：标题、段落或行范围；
- HTML/XML：章节标题或元素标识。

## 核验要求

- 记录文献真实研究人群、设计、样本量和结局定义。
- 数字必须与原文一致。
- 方向性结果需要记录比较组和时间点。
- 调整后结果需要说明调整模型。
- 次要分析、亚组分析和探索性分析需要标记。
- 摘要与全文冲突时采用全文并记录冲突。
- 引用二手来源时明确其二手属性。

## 不可读来源

不可提取文本的扫描 PDF 需要人工转为可搜索文本。缺失全文时可以保留为候选来源，不能设置 `verified_full_text: true`，不能进入正式草稿。
